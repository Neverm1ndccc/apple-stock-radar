# 离线与本机验收方案

## 常规检查

运行 `cargo test --offline`、`cargo fmt --all --check`、`cargo clippy --offline --all-targets -- -D warnings`、`pnpm build`、`pnpm test`。不运行 Apple live 测试，不联网刷新目录。

Rust 回归覆盖：中港目录与 URL、2×3 组合/去重/跨区拒绝、状态转换、过期与恢复、同 ID 幂等与冲突、首次提醒开关、投递 claim、失败隔离、目标与全局暂停、模拟隔离、统计分母及本地偏移、5000 以上完整导出、备份恢复和无效备份拒绝、高版本数据库保护。

前端测试覆盖：型号/容量/地区组合过滤、隐藏或重复选中项清理、搜索/状态/分组筛选、零分母展示与 Bark URL 错误脱敏。

## 界面隔离验收

用 `radar-core/examples/ui_fixture.rs` 在内存生成 fixture。`tests/ui.html` 使用 Tauri 官方 mockIPC，仅验证展示与命令参数，不替代 Rust 或原生 IPC 测试，不改用户数据库。检查：空态、批量 2×3 预览、地区切换、记录对话框、历史/覆盖提示、设置默认开关、诊断、托盘尺寸、亮暗模式。

## 本机原生验收

验证 `.app` 可打开，主窗口与菜单栏存在；通过界面建立目标并录入，关闭窗口后从菜单栏打开；退出重启后数据保留。单独记录原生通知授权与展示、Bark 真凭证手机端接收、登录启动、睡眠恢复、多显示器、拒绝权限、断网与 24–72 小时稳定性。这些不能用短时构建或 mock 通过替代。

测试结果与未完成项记录在 TEST_REPORT.md。不得把没有执行的场景标为通过。

## v0.2.0 扫描扩展

新增 scanning.rs 的 16 项离线测试：中港批次/URL、真实字段解析、缺失/矛盾字段、HTML/错误信封、未获准/过期/地区范围、间隔和重叠、配置变化、休眠、网络退避、拒绝停用、取消/重启预算、来源恢复后的旧样本信任、Apple 与手动/模拟历史和投递隔离、v1 数据库与备份升级。

隔离界面验证 17 秒保存与 0 秒拒绝；原生验证 120 秒持久化后恢复默认 300 秒，确认无许可时真实扫描控件禁用。
